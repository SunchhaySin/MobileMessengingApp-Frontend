# AI Messenger App

This app is a mobile oriented messenging app, intended for developing mobile coding skills, and will also serve as an acedemic resource that will be used as reference in the furture. It will in be built using these frameworks/libraries detailed below :

### Technology Used :
- Flutter && Dart (Frontend)
- Express/ Nodejs (Backend)
- Socket.io (Continous Connection between server/client)
- PostgreSQL (Database)
- SUPABASE (Postgres Database Server)
- Redis (Real Time User Interaction: Online or Typing)
- Firebase Cloud Messenging (Push Notifications)
- Prisma (Simplify Database Query)
